A tiny original flight game for the browser: fly the mail plane *Kestrel*
over the Coral Run archipelago. Thread the five gold rings, drop the parcel
on the village bullseye, then land gently on the home runway — before the
fuel runs dry or the airframe gives up.

- Chase and cockpit views (C), lit instruments: attitude ball, altimeter,
  airspeed, heading compass, fuel and damage gauges, annunciator lamps.
- Keyboard (arrows/WASD, Shift/Ctrl throttle) and mouse steering.
- Synthesized engine, wind and chime audio — no files, no network.
- Deterministic `?shot=` scenes for the entry screenshots.

Play locally: `node serve.ts`, then open the page it prints.
Hand in: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
